# Diretório Raiz

## Versão
- v0.1.0 — 2025-09-15 — Documentação inicial das funções de cada arquivo.

## Descrição de Arquivos
- index.html: Landing page pública com CTA para autenticação, formulário de lead e seções de recompensa.
- auth.html: Fluxo de login/cadastro com verificação de e-mail.
- members.html: Área de membros para progresso da missão de onboarding e envio de provas.
- styles/: Folha de estilos principal (ver documentação da pasta).
- scripts/: Scripts modulares para Firebase, PlayFab e lógica de missão.
- data/: Catálogos de missões e schemas de apoio.
- assets/: Imagens e áudios utilizados nas páginas.
- firestore.rules: Regras do Firestore recomendadas para o projeto.
- storage.rules: Regras do Firebase Storage para uploads de provas.
- PROGRESS.md: Registro contínuo do que foi feito, pendências e próximos passos.
- RULES.md: Convenções de trabalho que devem ser seguidas antes de novas alterações.
