# codes/

## Versão
- v0.1.0 — 2025-09-15 — Estrutura para códigos resgatáveis no site.

## Uso
- Adicione arquivos JSON com o nome do código (por exemplo, alpha.json).
- O conteúdo pode conter campos como "html", "message" ou qualquer payload customizado.
- Se preferir usar automação, configure {N8N_REWARD_WEBHOOK} para responder ao POST enviado pelo módulo de recompensas.

## Observações
- Mantenha apenas códigos públicos aqui; códigos privados podem ser servidos via webhook seguro.
